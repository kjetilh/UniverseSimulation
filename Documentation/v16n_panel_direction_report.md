## Verified evidence entering the panel

The frozen v16m holdout used twelve new histories and the v16l-qualified attempt ceiling. All `384/384` primary and `192/192` longer perturbations passed the declared integrity contract. The primary `exposure_matched_local` arm had median full-spectrum JS effect ratio `12.417734`, positive direction in `6/6` runs, and empirical `p <= 0.10` in `5/6`. The longer perturbation had median ratio `14.222428` and positive direction in `6/6`.

Every primary `tail_mass_ge_8_delta` was negative. The supported object is therefore a full interval-spectrum contrast, not an increase in large intervals. Completion and integrity do not establish sampler convergence, stationarity, independence, representativeness, irreducibility, or uniformity.

## Panel roles and convergence

Four remote advisers were used with controlled common context:

- experimental design: compare another fresh replication, scale-up, and an event/resource-aware null;
- statistical skepticism: attack exchangeability, conditioning, post-selection, pseudo-replication, and sampler claims;
- causal-order implementation: inspect event metadata and propose legal constrained swaps;
- claim adjudication: define the strongest safe claim under every result branch.

The panel was not treated as a vote. All roles preferred an event/resource mechanism gate after v16m. Another replication would mostly repeat the same unresolved mechanism alternative. Scale-up would estimate an unresolved contrast more precisely without explaining it.

## Selected v16n design

Extend the v16j directed double-edge swap. For any scheduler-ordered event pair `u -> v`, derive a coarse color from structured fields only:

`(family[u], family[v], conflict_direction, resource_namespace)`.

Conflict directions are `write-read`, `write-write`, and `read-write`. A channel exists only when the corresponding read/write sets share a complete concrete resource identifier. Only the namespace prefix before `:` enters the color. The free-text descriptor is never used.

For a proposed swap `(a -> b, c -> d)` to `(a -> d, c -> b)`, the multiset of the two coarse colors must be unchanged. Every v16j order, duplicate-edge, exact degree, exact depth, and global dyadic age-bin condition remains in force.

The first v16n round is calibration only:

- generate or select a calibration corpus that is disjoint from the formal v16m histories;
- inspect only metadata mapping, eligible support, completion, preservation, changed-edge fraction, uniqueness, attempts, and bucket movement;
- do not compute interval spectra during sampler selection;
- freeze the color function, ceiling ladder, thresholds, seeds, status map, and source hashes before calibration;
- stop as `sampler_not_qualified` if no frozen ceiling satisfies every primary and longer calibration perturbation.

If calibration succeeds, applying the frozen null to v16m is a post-hoc mechanism sensitivity analysis, not another fresh confirmation. A later genuinely new history holdout is required before claiming fresh replication under the new null.

## Decision branches

- Calibration fails: report `v16n_coarse_event_resource_sampler_not_qualified`; do not evaluate spectra.
- Calibration succeeds but formal preservation/completion fails: report instrumentation failure; make no new scientific claim.
- Valid formal contrast persists: coarse declared event/resource wiring is insufficient to absorb the contrast under this sampler.
- Valid formal contrast is absorbed: the v16m contrast is compatible with being generated by the declared coarse event/resource wiring.
- Mixed primary/longer or partial attenuation: report mechanism-inconclusive.

No branch proves sampler uniformity or a physical geometry.
