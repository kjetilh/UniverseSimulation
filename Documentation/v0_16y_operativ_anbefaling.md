# Operativ anbefaling etter v16y

Status: `v16y_2x2_chain_finite_centers_not_stable`.

Behold 2x2-kjeden som en eksakt reversibel lokal kontroll, men ikke som kvalifisert global nullfordeling. Neste gate er en effektblind alternerende-syklus/bridge-audit som skiller utilstrekkelig lokal rekkevidde fra mulig move-komponentseparasjon foer mer samplerbudsjett brukes.

Ikke aapne v16s-effekten, og ikke kall startseparasjonen bevis for disjunkte komponenter, mixing-feil, fysikk eller universell geometri.
