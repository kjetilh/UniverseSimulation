# Relasjonell universgraf v0.14c for ikke-spesialister

Denne runden testet om forskjeller mellom ulike steder i grafen kan forklares av enkel lokal geometri rundt inngrepet.

Hoveddommen er `weak`.

Det betyr: Ingen av de testede støttegeometriene, inkludert `support_ball_3`, forklarer hastighetsvariasjonen særlig godt.

Neste anbefaling er: Ikke utvid Lorentz-sporet bredt ennå; bruk heller dette til å vurdere om videre isotropitesting er verdt kostnaden.
