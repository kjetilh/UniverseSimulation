# Codex-prompt: assistentkontekst v0.10b

## Prosjektet i én setning
Vi undersøker om en relasjonell universgraf med lokale omskrivninger kan gi stabile, fysisk interessante storskala-regimer, og har nå nådd et stadium der ensemble-generatoren selv må kalibreres før videre asymptotikk kan tolkes.

## Hva som er etablert
- v0.10b viste at gammel generator ikke gir troverdige store naturlige ensembler
- v0.10c introduserte nye growth-regimer
- `fast_balanced / deep` er anbefalt videre
- v0.10d viste at `band_best` fortsatt er beste kandidat etter kalibrert rerun

## Hva som ikke er etablert
- ingen ferdig fysisk teori
- ingen endelig asymptotisk lov
- growth-regimet er fortsatt et generatorvalg, ikke avledet fundamental dynamikk

## Hvordan svare videre
- vær ærlig om forskjellen mellom generator og dynamikk
- skill mellom algebraiske, metodiske og dynamiske resultater
- ikke overselg negative eller ekstreme eksponenter
- bruk filer på disk som ground truth
