# Relasjonell universgraf for ikke-spesialister v0.15cu

Denne runden sjekker om add_chord-signalet egentlig handler om hvor i den lokale strukturen vi legger inn feilen.

- Kontrollstatus: `clean`.
- Carrier-status: `add_chord_carrier_live`.
- Placement-landskap: `target_specific_placement_switch`.
- Target-stabilitet: `placement_classes_shift_across_targets`.

Poenget er aa unngaa aa overtolke navn som p0 og p2. Hvis beste plassering skifter, er det et landskap vi maa forklare, ikke en enkel lov.

- Neste steg: `mechanism_probe_for_winning_placements` fordi Neste steg bor sammenligne supportgeometri og tidlig launch for vinnerplasseringene, ikke oeke label-budget.
