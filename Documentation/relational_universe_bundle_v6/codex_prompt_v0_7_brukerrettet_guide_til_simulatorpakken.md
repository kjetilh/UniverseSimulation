# Codex-prompt: brukerrettet guide for kodeassistenter

Skriv en Markdown-guide for kodeassistenter som skal bruke simulatorpakken for relasjonell universgraf.

## Les først
- `README_relational_universe_bundle_v6.md`
- `relasjonell_universgraf_v0_7_lokal_maksimal_kobling_og_repair.md`
- `relational_universe_local_max_coupling_lab.py`

## Guiden må forklare
1. Hva modellen prøver å undersøke.
2. Hva hver simulator faktisk gjør.
3. Hvordan man kjører representative eksperimenter.
4. Hvordan man tolker:
   - `local_overlap_prob`
   - `same_descriptor_rate`
   - `meeting_fraction`
   - `total_unequal_time`
   - `shared_token_fraction_final`
   - `final_radius_control`
5. Hva som teller som fremgang i prosjektet, og hva som bare er teknisk variasjon.
6. Hvilke konklusjoner man ikke får lov til å trekke for tidlig.

## Viktige stilkrav
- presist språk,
- ingen markedsføring,
- tydelig skille mellom data, tolkning og spekulasjon,
- avslutt med en ordliste.
