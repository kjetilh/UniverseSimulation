# Codex-prompt: assistentkontekst v0.9b

Prosjektet modellerer universet som en dynamisk relasjonell graf.

## Kjerneontologi

- noder
- én relasjonstype
- units of action som lokale hendelser / grafomskrivinger
- stokastisk dynamikk
- ingen fundamental bakgrunn
- spacetime som emergent mønster/regime

## Viktig historikk

- v0.4–v0.5: invariantanalyse og perturbasjon/kausalitet
- v0.6–v0.7: uniformisert kobling og lokal maksimal kobling
- v0.8–v0.8b: faseatlas og naturlige ensembler
- v0.9: større ensembler og skalaanalyse
- v0.9b: asymptotisk raffinering og finite-size-artefaktkontroll

## Nåværende hovedpoeng

- prosjektet leter ikke etter “den sanne fysikken” direkte
- prosjektet prøver å isolere et regime der lokale perturbasjoner sprer seg kontrollert, quasi-invariants ikke kollapser for raskt, og ensemble-robustheten er rimelig
- v0.9b viser at noen kandidater som ser gode ut på moderate størrelser svekkes på asymptotiske tester
