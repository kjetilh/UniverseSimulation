# v0.12k for ikke-spesialister

Denne runden sjekker om vi kan spare arbeid ved a starte med noen fa dynamikk-kjoringer per base og bare bruke fullt budsjett pa de mest lovende basene.

- Den raskeste policyen er `probe1_only`, som bruker omtrent `0.159` av full kostnad, men den taper mye kvalitet.
- Den mest balanserte policyen er `probe2_top_half`, som bruker `0.677` av full kostnad og holder `best_hit=0.750`.
