# Prosjektoversikt v0.10e

## Hvor prosjektet står nå

Prosjektet startet som en bakgrunnsløs idé om universet som en dynamisk relasjonsgraf av noder, relasjoner,
tilfeldighet og units of action. Etter hvert er dette blitt omgjort til en serie stadig strengere simulasjons- og analysefaser.

Hovedlinjen så langt er:

1. **Minimal ontologi og lokale rewrite-regler**
   - én relasjonstype
   - partikler, felt og spacetime som emergente mønstre
   - entanglement tolket som korrelasjon, ikke som signaleringskanal

2. **Invariant- og energiarbeid**
   - topologiske og kvasi-bevarte størrelser
   - skille mellom eksakt invariant, lokal kontinuitet og emergent quasi-invariant

3. **Kausalitets- og repair-lab**
   - kopla replikater
   - lokal perturbasjon
   - målinger av radius, overlap og spredning

4. **Fasekart og naturlige ensembler**
   - identifisering av lovende parameterbånd
   - testing på større og mer naturlige startkonfigurasjoner

5. **Generatorreparasjon i v0.10b–v0.10d**
   - nominelle store ensembler var ikke egentlig store
   - nytt growth-regime måtte innføres
   - `fast_balanced / deep` ble anbefalt som standard

6. **Lokal bandvalidering i v0.10e**
   - prosjektets sentrum ble flyttet fra `band_best` til en ny to-kandidat-front:
     `band_zero_del` og `band_small_triad`

## Hva som nå er viktigst

Det viktigste er ikke å utvide parameterrommet ukritisk, men å bruke mer replikasjon
på den nye lokale fronten og se om den holder når man finjusterer én eller to ekstra akser.
