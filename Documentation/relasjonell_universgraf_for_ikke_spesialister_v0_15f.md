# Relasjonell universgraf v0.15f for ikke-spesialister

Denne runden brukte ekstra målebudsjett på ett bestemt lokalt defect-par for å se om mønsteret ble tydeligere.

Hoveddommen er `compress_then_split_leading_but_mixed`.

Det betyr: `compress_then_split` leder for pair 2-3 (0.125), men mixed-andelen er fortsatt for høy (0.750) til en ren dom.

Neste anbefaling er: Neste steg bør være enda mer budsjett på samme base eller en enda strammere seed-familie rundt de run-offsettene som støttet signalet.
