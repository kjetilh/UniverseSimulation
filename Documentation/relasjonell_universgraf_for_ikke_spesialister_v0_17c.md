# Relasjonell universgraf v0.17c for ikke-spesialister

V17c endrer ikke hvilke graf-flytt som kan velges. Den teller de samme mulighetene uten aa lagre hele listen, og bruker ett tilfeldig nummer til aa velge samme plass i den samme rekkefolgen. Dermed kan vi kreve noyaktig samme kjede som i v17b og maale bare tidsgevinsten.

Statusen er `v17c_exact_counter_runtime_qualified`. En bestaa-status kvalifiserer bare denne endelige algoritmen for neste stabilitetstest. Den er ikke bevis for kvantefysikk, romtid eller et univers.
